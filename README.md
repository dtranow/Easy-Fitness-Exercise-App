# Easy Fitness

## Overview
**Easy Fitness** is an AI-enhanced exercise guide application that helps users explore exercises, learn techniques, and ask exercise-related questions through an integrated AI chatbot.

## Features
- **Exercise Search**: Search for exercises by name, target muscle, body part, or equipment
- **AI Chatbot**: Get instant answers to exercise-related queries with an AI chatbot.
- **Dynamic Content**: Explore exercise instructions, GIFs, and other related content including youtube instruction videos and similar exercises fetched in real-time.
- **Dark Mode**: An easy toggle for user-friendly viewing in low-light conditions at the navigation bar.
- **Pagination**: View many different exercises in a paginated format for easy navigation.
